## Architecture

**usfm-js** is a bidirectional USFM ↔ JSON converter. USFM (Unified Standard Format Marker) is the Bible translation markup standard.

### Public API (`src/index.js`)

- `toJSON(usfmText, options)` — parses USFM into a structured JSON object
- `toUSFM(jsonData, options)` — serializes JSON back to USFM string
- `removeMarker(string)` — strips all USFM markers, returns plain text

### Core Modules

**`src/js/usfmToJson.js`** — Parser  
Tokenizes USFM by regex, walks markers sequentially, and builds a nested `verseObjects` tree. State is tracked via a mutable params object (current chapter, verse, open tag stack). Key edge cases: word attributes (`\w word | key="val"\w*`), alignment milestones (`\zaln`), verse bridges, and BOM stripping.

**`src/js/jsonToUsfm.js`** — Serializer  
Iterates JSON chapters/verses and reconstructs USFM marker strings. The `forcedNewLines` option controls whether paragraph markers get explicit newlines. Word attributes and milestone self-closing tags are reconstructed from the stored JSON attribute maps.

**`src/js/USFM.js`** — Marker Definitions  
Single source of truth for all USFM tag metadata. `USFM_PROPERTIES` maps every tag name to its properties (`endTag`, `display`, `type`, `attrib`, `milestone`, `standalone`). To add a new marker, add an entry here. `SPECIAL_END_TAGS` maps non-standard end tag forms to their opening counterparts (e.g., `qt-e` → `qt-s`).

**`src/js/filter.js`** — Utility  
`removeMarker` calls `usfmToJSON` internally and flattens verseObjects to extract display text.

### JSON Output Shape

```json
{
  "headers": [...],
  "chapters": {
    "1": {
      "1": { "verseObjects": [...] },
      "2": { "verseObjects": [...] }
    }
  }
}
```

Each `verseObject` is `{ type, tag, text, ... }`. Words have `{ type: "word", text, strong, ... }`. Milestones (e.g., `\zaln`) carry their attributes and wrap child `children` arrays.

### Test Fixtures

`__tests__/resources/` holds paired `.usfm` and `.json` files. Round-trip tests in `roundTrip.test.js` convert USFM → JSON → USFM and compare the result to the original. When adding new marker support, add fixture files and a corresponding round-trip test entry.

`__tests__/util.js` provides `readUSFM(filename)` and `readJSON(filename)` helpers for loading fixtures.

### Build Output

`lib/` is generated by Babel (`npm run build`) and is the published package entry point. Do not edit files in `lib/` directly.
